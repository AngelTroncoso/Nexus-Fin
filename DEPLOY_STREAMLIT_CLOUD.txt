PASO 2: CREAR NUEVA APP
═══════════════════════════════════════════════════════════════

1. Clic en "New app" (botón azul arriba a la derecha)

2. Completa el formulario:

   Repository:
   ┌─────────────────────────────────────────┐
   │ AngelTroncoso/Nexus-Fin                 │
   └─────────────────────────────────────────┘

   Branch:
   ┌─────────────────────────────────────────┐
   │ main                                    │
   └─────────────────────────────────────────┘

   Main file path:
   ┌─────────────────────────────────────────┐
   │ app.py                                  │
   └─────────────────────────────────────────┘

   App URL (personalizable):
   ┌─────────────────────────────────────────┐
   │ nexus-fin-angel                         │
   └─────────────────────────────────────────┘

═══════════════════════════════════════════════════════════════

PASO 3: CONFIGURAR API KEY (OPCIONAL)
═══════════════════════════════════════════════════════════════

Si quieres usar el LLM real:

1. Clic en "Advanced settings"
2. En la sección "Secrets", pega esto:

   ┌─────────────────────────────────────────┐
   │ OPENROUTER_API_KEY = "tu_clave_aqui"    │
   │ OPENROUTER_MODEL = "nvidia/nemotron-3-nano-30b-a3b:free" │
   └─────────────────────────────────────────┘

   📌 Obtén tu clave en: https://openrouter.ai/keys

   ⚠️ IMPORTANTE: Sin API key, el sistema funciona
                   en modo fallback (lógica heurística)

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

❌ "ModuleNotFoundError"
   → Verifica que requirements.txt esté en el repo

❌ "App no inicia"
   → Revisa los logs en Streamlit Cloud
   → Botón "Manage app" → "Logs"

❌ "Gráficos no se ven"
   → Refresca el navegador (Ctrl+F5)

❌ "Error de API"
   → Es normal sin API key configurada
   → El sistema funciona en modo fallback
