============================================
FLUJO DE EJECUCIÓN
============================================

1. Usuario configura escenario en Streamlit UI
2. Sistema crea scenario_data con métricas
3. RouterEngine analiza y consulta LLM (OpenRouter)
4. LLM decide: Ruta A (Predictivo) o Ruta B (Adaptativo)
5. Motor seleccionado genera proyección/trayectoria
6. Resultados visualizados en Plotly con métricas

============================================
DECISIONES DE ARQUITECTURA
============================================

✓ OpenRouter: Acceso multi-modelo con una API
✓ Streamlit: Prototipado rápido e interactivo
✓ Plotly: Gráficos profesionales sin JavaScript
✓ Módulos separados: Fácil extensión y testing
✓ Modo fallback: Resiliencia ante fallas de API
✓ JSON explícito: Transparencia total del LLM

============================================
ESCENARIOS SOPORTADOS
============================================

1. Entorno Estable
   - Volatilidad: 5%
   - Sin shocks
   - Decisión esperada: Ruta A (Predictivo)

2. Shock de Liquidez Crítico
   - Volatilidad: 28%
   - Shocks detectados
   - Decisión esperada: Ruta B (Adaptativo)

============================================
MÉTRICAS GENERADAS
============================================

Motor Predictivo (A):
  • Flujo promedio proyectado
  • Desviación estándar
  • Bandas de confianza (95%)
  • Volatilidad index
  • Proyección min/max

Motor Adaptativo (B):
  • Número de rebalanceos
  • Eventos de shock manejados
  • Impacto total de shocks
  • Eficiencia de recuperación
  • Flujo min/max
